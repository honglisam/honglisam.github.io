🎯 OpenClaw 实战教程

使用 OpenClaw
制作个人主页

从零开始，30 分钟打造你的专属个人主页

开始学习 查看源码
1

准备工作

在开始之前，你需要准备以下工具：

  • 已安装 OpenClaw（AI 助手）
  • 已注册 GitHub 账号
  • 准备好个人照片（头像、生活照等）
  • 准备好个人信息（姓名、简介、技能等）

💡 提示：OpenClaw 是一个强大的 AI 助手，可以帮你自动完成代码编写、图片压缩、Git 推送等操作。

2

创建 GitHub 仓库

1. 登录 GitHub，创建新仓库

仓库名称：你的用户名.github.io
例如：honglisam.github.io

2. 克隆仓库到本地

git clone https://github.com/你的用户名/你的用户名.github.io.git
cd 你的用户名.github.io

💡 提示：GitHub Pages 会自动部署这个仓库，访问地址就是 https://你的用户名.github.io

3

告诉 OpenClaw 你的需求

向 OpenClaw 描述你想要的个人主页：

"帮我创建一个个人主页，要求：
1. 使用极深色背景（#050507）
2. 纯白色文字，不要用彩色渐变
3. 简洁的布局，类似 EasyClaw 风格
4. 包含以下信息：
   - 姓名：松石
   - 身份：连续创业者
   - 所在地：杭州
   - 学历：浙江理工大学计算机硕士
   - 技能：连续创业、运动营养、儒释道文化等
   - 联系方式：微信、邮箱"

💡 提示：描述越详细，OpenClaw 生成的页面越符合你的预期。可以强调"严格抄袭"某个网站的风格。

4

提供个人照片

将你的照片发送给 OpenClaw，它会自动：

  • 保存照片到项目目录
  • 压缩图片（保证清晰度同时减小文件大小）
  • 更新 HTML 中的图片引用
  • 提交并推送到 GitHub
示例照片处理：
原始照片：4.3MB
压缩后：18KB（头像）/ 50KB（照片预览）/ 85KB（高清大图）
压缩率：99%+
加载速度：从几秒变成毫秒

💡 重要：图片一定要压缩！否则网页加载会很慢。但二维码等需要扫描的图片不要压缩太狠。

5

迭代优化

根据预览效果，不断提出修改意见：

常见修改需求：
- "把导航栏删掉"
- "照片比例失真了，修复一下"
- "手机上改成左右滑动"
- "联系我按钮改成弹出二维码"
- "隐藏出生年份等隐私信息"
- "缩短各个区域的间距"
- "技能栈改成生活爱好"

💡 提示：每次修改后，OpenClaw 会自动提交推送到 GitHub，你可以实时查看效果。

6

添加微信二维码

发送你的微信二维码给 OpenClaw：

"这是我的微信二维码，添加到联系我区域。
要求：
1. 不要压缩太狠，要保证清晰可扫
2. 点击按钮弹出二维码大图
3. 桌面端直接显示二维码"

OpenClaw 会：

  • 保存二维码原图（保证清晰度）
  • 创建弹窗组件
  • 添加点击事件
  • 优化移动端展示
7

移动端优化

确保手机端体验良好：

移动端优化要点：
- 技能栈：左右滑动展示
- 兴趣爱好：左右滑动展示
- 联系我：层叠卡片滑动
- 图片：固定高度，object-cover 保持比例
- 间距：适当缩小，减少滚动距离

💡 提示：使用 Tailwind CSS 的响应式类（如md:、lg:）可以轻松实现桌面端和移动端的差异化布局。

✓

完成！

现在你的个人主页已经上线了！访问 https://你的用户名.github.io 即可查看。

🎉 恭喜：你已经成功使用 OpenClaw 创建了一个专业的个人主页！整个过程只需要和 AI 对话，无需手动编写代码。

关键技术点总结

  • 图片压缩：使用 System.Drawing 压缩，保证清晰度的同时减小 90%+ 体积
  • 响应式设计：Tailwind CSS 实现桌面端和移动端自适应
  • 滑动效果：CSS scroll-snap 实现流畅的左右滑动
  • 弹窗组件：原生 JavaScript 实现照片和二维码弹窗
  • Git 自动化：OpenClaw 自动执行 git add/commit/push
